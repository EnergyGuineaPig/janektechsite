ABOUT

Your Minecraft versions, mods and servers

JanekLauncher 2 is a custom Minecraft launcher designed to make switching between Minecraft versions, modpacks and accounts simple.

Choose a Minecraft version, select your account and press PLAY. If Minecraft is not installed, JanekLauncher 2 can download the required files automatically.

Create a custom version with a name, Minecraft version and mod loader. Then add local mods or download them from Modrinth in the Mods tab. Each custom version keeps its own game folder.

FEATURES

What it can do

Minecraft versions

  • Launch releases, old beta versions and old alpha versions
  • Automatic Minecraft installation
  • Create named custom versions with separate game folders

Mods and Modrinth

  • Search and download mods directly without an API key
  • Filter files by Minecraft version and mod loader
  • Choose a release and include required dependencies
  • Download progress and checksum verification
  • Add local JARs, enable or disable mods, remove mods and open the mod folder

Custom versions and modpacks

  • Forge, NeoForge, Fabric and Quilt support
  • Custom replacement client JAR support
  • Import JanekLauncher modpack ZIP files
  • Export a custom version and its mods as a modpack

Accounts and Java

  • Microsoft sign-in and saved login
  • Offline profiles with custom token and UUID controls
  • Offline token and UUID generators
  • Select your own Java installation
  • Clear cache and forget the saved Microsoft login

Tabs and game tools

  • Dedicated Main, Mods, Servers, News, Game Console and Settings tabs
  • Saved servers and quick launch into a selected server
  • Minecraft news tab
  • Live Minecraft output in the Game Console
  • Optionally switch to the console when Minecraft starts
  • Image background from icons/back.png
