ABOUT

Create Minecraft servers more easily

MCC 5 is a Minecraft server manager for Windows. Start by creating or opening a project for one server or a network with a proxy and multiple servers. The native Qt light interface keeps the current project's servers and files together, with separate areas for the overview, console, files and settings. Install or import servers, manage their Java and memory settings, create backups, and configure JanekNetwork from the project overview.

01

Projects for servers and networks

Create or open a project. The sidebar shows only that project’s servers, with expandable folders and file icons.

02

Native Qt light interface

A clear project overview, grouped actions, helpful descriptions and built-in Help. MCC uses one native Qt light appearance.

03

Java and RAM per server

Detect Java automatically or select a custom executable. Each server has its own RAM, port and startup settings.

04

Built-in file editor

Open text configuration files inside MCC, save with Ctrl+S, upload files, and create files or folders. Unsaved changes are protected.

05

Console and server controls

Start and stop individual servers or the whole project. View live console output, send commands and check server status.

06

Backups and timed tasks

Create, list, restore and delete numbered world backups. Schedule daily server actions while MCC is open.

07

JanekNetwork and domains

Configure JanekNetwork to publish your server. You can also connect a domain you own through your DNS provider; Help explains the setup.

08

Organized project storage

New and imported servers use projects / project name / servers / server name under %APPDATA%\.mcc. Existing registered servers can keep their original locations.

09

Mods, plugins and MCC addons

Manage mods and plugins in the server workspace, and extend MCC with Python addons and custom MCC commands.

10

Server and proxy installation

Install or import server software and configure a proxy for a multi-server network. Keep each server’s configuration separate.
