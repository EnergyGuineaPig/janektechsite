ABOUT

Create installers without complicated setup

Setup MK4 Creator is a Windows installer builder made for developers who want an easier way to package and distribute their applications.

Import your application as a ZIP archive, configure the application name, version, publisher, installation directory and license agreement, then let Setup MK4 Creator generate the final installer executable.

The builder automatically prepares the installer source, runs the build process and outputs a ready-to-distribute Windows setup file.
